# **App Name**: HealthWise

## Core Features:

- Health Data Input: Secure form for entering health data. Fields include relevant medical history and current symptoms.
- Risk Prediction: Use a pre-trained AI model tool to predict the likelihood of diabetes or heart disease based on user-provided data. Model selection dynamically adapts based on user input.
- Results Display: Display prediction results with clear explanations and actionable recommendations.  Present risk factors and suggest lifestyle adjustments.

## Style Guidelines:

- Primary color: Calming teal (#4DB6AC) for a sense of health and well-being.
- Secondary color: Light grey (#EEEEEE) for a clean, modern background.
- Accent: Soft orange (#FFAB91) to highlight key information and calls to action.
- Clean, card-based layout for easy readability and clear information hierarchy.
- Use simple, health-related icons for key features and information.
- Subtle transitions and animations to provide feedback and enhance user experience.
